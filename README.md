# Ответы на вопросы
9) Почему G3 = 0 нельзя автоматически считать неявкой на аттестацию?
   Потому что причина нулевой оценки в данных не указана: это может быть болезнь, переезд, семейные обстоятельства, непрохождение аттестации по иным причинам. Сочетание G3 = 0 при G1 > 0 (в моём наборе 38 записей) - лишь маркер необычной комбинации оценок, требующий уточнения у педагога, а не доказательство отсутствия на экзамене. Поле «G3=0 при G1>0» создано именно как индикатор для внимания, а не как диагноз.
10) Какие сведения допустимо публиковать в открытом педагогическом дашборде и почему?
  Только обезличенные учебные признаки: учебные коды S001–S395, оценки G1–G3, группы пропусков и неосвоенных курсов, агрегированные показатели. Недопустимы фамилии, возраст, пол, здоровье, состав семьи и другие сведения - они исключены ещё на этапе подготовки таблицы, так как публичный дашборд и выгружаемые из него данные может открыть и скачать любой, у кого есть ссылка, поэтому публикация персональных данных нарушила бы требования закона № 152-ФЗ «О персональных данных»
